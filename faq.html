Frequently Asked Questions

Hier findest du Antworten auf häufige Fragen rund um die Nutzung von PatternLab.

Was ist PatternLab?

PatternLab ist eine Webanwendung zur Organisation von Häkel-, Strick- und anderen Handarbeitsprojekten mit PDF-Anleitungen, Checklisten, Notizen und Fortschritt.

Wo werden meine Daten gespeichert?

Aktuell werden alle Daten lokal im Browser im sogenannten LocalStorage gespeichert. Das bedeutet, dass die Daten ausschließlich auf dem jeweiligen Gerät und im verwendeten Browser gespeichert werden.

Die Daten werden derzeit nicht auf einen Server übertragen oder online synchronisiert. Dadurch sind sie nur auf dem Gerät verfügbar, auf dem sie erstellt wurden.

Für zukünftige Versionen wird an einer Lösung gearbeitet, die eine geräteübergreifende Speicherung ermöglicht.

Brauche ich ein Benutzerkonto?

Nein. Aktuell ist kein Benutzerkonto erforderlich.
PatternLab befindet sich derzeit noch in einer frühen Entwicklungsphase und nutzt kein Backend. Deshalb können Projekte direkt im Browser gespeichert und verwendet werden, ohne dass eine Anmeldung notwendig ist.

Welche Accessibility-Funktionen bietet PatternLab?

PatternLab wurde unter Berücksichtigung ausgewählter Anforderungen der WCAG 2.1 AA entwickelt.
Ein Kontrastmodus sowie eine Schriftgrößenanpassung sind über eigene Buttons verfügbar. Zusätzlich sorgen eine klare Seitenstruktur und beschriftete Formularfelder für eine bessere Zugänglichkeit.

Wie füge ich eine PDF-Anleitung hinzu?

Momentan können PDF-Anleitungen über eine öffentlich zugängliche URL eingebunden werden.
Die PDF-Datei muss online erreichbar sein. Eine Möglichkeit besteht darin, die PDF-Datei in ein GitHub-Repository hochzuladen und über GitHub Pages bereitzustellen. Alternativ kann die Datei auch auf einem anderen Webserver liegen oder eine bereits öffentlich verfügbare PDF verwendet werden.
Anschließend wird die direkte URL der PDF in PatternLab hinterlegt, sodass die Anleitung im jeweiligen Projekt angezeigt werden kann.

Kann ich meine Projekte auch offline sehen?

Grundsätzlich ja.
Da die Projektdaten lokal im Browser gespeichert werden, können bereits gespeicherte Projekte auch ohne Internetverbindung genutzt werden.
Für eingebundene PDF-Dateien ist jedoch weiterhin eine Internetverbindung erforderlich, sofern die PDF-Datei online gehostet wird.

Was passiert, wenn ich ein Projekt lösche?

Beim Löschen eines Projekts werden alle zugehörigen Informationen aus dem LocalStorage entfernt. Dazu gehören beispielsweise Projektdaten, Notizen, Checklisten und Fortschrittsinformationen.
Dieser Vorgang kann derzeit nicht rückgängig gemacht werden.

Werden meine Daten an einen Server übertragen?

Nein.
Aktuell werden keine Projektdaten an einen externen Server übertragen. Alle Informationen verbleiben lokal im Browser des verwendeten Geräts.

Ich habe Ideen, Anregungen, Feedback oder weitere Fragen. Was kann ich tun?

Da sich PatternLab noch in der Entwicklung befindet, sind Rückmeldungen jederzeit willkommen. Besonders hilfreich sind Vorschläge zu neuen Funktionen, Verbesserungsideen oder Hinweise auf Probleme bei der Nutzung.
